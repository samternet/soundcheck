# Genre artwork

## Source

These images were created for Soundcheck with an AI image generator. They
are original artwork, not photos of real artists or copies of album covers, and
are distributed with the project under its license (see `LICENSE`).

Replace these placeholder `.webp` files with your own genre artwork. The Genre page expects square 1200×1200 WebP images.

36 named genre assets plus `default.webp` are included. The app maps detailed Jellyfin genre tags into these artwork families where possible and falls back to `default.webp` for anything else.

The artwork should not contain essential text because the UI overlays the genre name, rank, and percentage.
